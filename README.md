# 解析数论基础

这是一个用于 GitHub Pages 的静态索引页，整理数论基础笔记、作业 PDF 与对应 TeX 源码。 这是我在2025-2026年学年春季学期林永晓老师授课的山东大学泰山学堂《数论基础》上的笔记和各类杂项的整理。 笔记可读性较高，班级里一部分同学都用来复习期末，并且取得了不错的成绩。
